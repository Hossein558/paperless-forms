# سامانه فرم‌های بدون کاغذ تولید (Jira Paperless Forms Plugin)

این مخزن حاوی کدهای منبع افزونه بومی جیرا (Jira Native Plugin) برای مدیریت فرم‌های بازرسی حین فرآیند تولید (In-Process Inspection) و مستندات مربوطه است.

---

## ساختار پوشه‌ها و مخزن

```text
├── paperless-forms-plugin/      # کدهای منبع افزونه بومی جیرا (Java 21 + AMPS 9.11.2)
├── documents/                   # مستندات نیازمندی‌ها، نقشه راه، الگوها و جداول داده‌ها
│   ├── database_schema.md       # سند طراحی و ساختار جداول پایگاه‌داده
│   ├── project_roadmap.md       # نقشه راه کلان پروژه
│   ├── implementation_plan.md   # برنامه پیاده‌سازی گام‌به‌گام
│   ├── jb stup.pdf              # مستندات نیازمندی‌های سیستم
│   ├── بازرسی حین فرایند.pdf     # جزئیات فرم‌های بازرسی حین فرآیند
│   └── کراس چک.pdf              # مستندات فرآیندهای متقابل کنترل کیفیت
└── troubleshooting/             # اسکریپت‌ها و گزارش‌های رفع اشکال در زیرساخت
    ├── walkthrough.md           # مستندات راه‌اندازی و اولین کامپایل موفق
    ├── task.md                  # چک‌لیست اقدامات پیاده‌سازی و وضعیت پیشرفت
    ├── test_ssh_offline.py      # اسکریپت تست اتصال SSH به سرور هدف عملیاتی
    └── test_ssh_vps.py          # اسکریپت تست اتصال SSH به سرور واسط متصل به اینترنت
```

---

## مشخصات فنی پروژه

- **نسخه جیرا:** `11.3.4` (Jira 11 Data Center)
- **نسخه جاوا:** `Java 21` (Oracle JDK / Eclipse Temurin)
- **ابزار توسعه:** `Atlassian Plugin SDK 9.11.2` (AMPS)
- **پایگاه‌داده:** `MS SQL Server 2019/2022`
- **تکنولوژی فرانت‌اند:** تعبیه React + TypeScript درون منابع وب افزونه (در دست ساخت)

## پایگاه‌داده و اتصالات

اتصال به پایگاه‌داده از طریق پورت اختصاصی برقرار شده است:
- **سرور:** `Jira-DB,63427`
- **پایگاه‌داده:** `Jira`
- **نام کاربری:** `jira`
- **کلمه عبور:** `147258369Qaz`

ساختار پایگاه‌داده شامل جداول زیر برای ثبت بازرسی‌ها است:
1. `PM_IPI_Parts`: لیست قطعات و ایستگاه‌های کنترل کیفی
2. `PM_IPI_Parameters`: پارامترهای کنترل کیفیت برای هر قطعه
3. `PM_IPI_Sessions`: نشست‌های بازرسی ثبت شده توسط بازرسان
4. `PM_IPI_Answers`: پاسخ‌ها و مقادیر اندازه‌گیری شده نمونه‌ها

## نحوه کامپایل و بسته‌بندی افزونه

برای ساخت و بسته‌بندی مجدد افزونه، دستور زیر را در پوشه `paperless-forms-plugin` اجرا کنید:
```bash
atlas-package
```
فایل خروجی `.jar` در مسیر `paperless-forms-plugin/target/` تولید شده و قابل آپلود در بخش مدیریت افزونه‌های جیرا است.
